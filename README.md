# Sort Numbers in Ascending Order

## Explanation

This Python program accepts a list of numbers and arranges them in ascending order, from the smallest number to the largest number.

## Problem Statement

Write a Python program to input a list of numbers and sort them in ascending order.

## Features

* Accepts multiple numbers.
* Stores numbers in a list.
* Sorts numbers from smallest to largest.
* Displays the sorted list.

## How It Works

1. Read numbers from the user.
2. Store them in a list.
3. Use the `sort()` method.
4. Display the list in ascending order.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `split()`
* `map()`
* `sort()`

## Program Flow

Input → Create List → Sort in Ascending Order → Display Result

## Sample Input

```text
50 20 40 10 30
```

## Sample Output

```text
Ascending order: [10, 20, 30, 40, 50]
```

## Time Complexity

O(n log n)

## Space Complexity

O(n)
